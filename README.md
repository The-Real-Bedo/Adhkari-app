## 📖 نبذة عن التطبيق
**أذكاري** هو تطبيق إسلامي حديث وخفيف الوزن، تم بناؤه باستخدام **Flutter** ليقدم تجربة مستخدم فريدة وسلسة. يركز التطبيق على دقة المواعيد والشكل البصري الفاخر (النيوني) لمساعدة المسلم على المحافظة على أوراده اليومية دون تشتيت.

> ⚠️ **حالة المشروع الحالية:** التطبيق ما زال في مرحلة **التطوير النشط والمكثف (Under Development)**، ويتم تحديث الكود وإضافة ميزات جديدة بشكل دوري.

## ⚡ المميزات الحالية (Current Features)

- [x] **🔔 نظام إشعارات ذكي:** جدولة أذكار الصباح والمساء بدقة متناهية بناءً على المنطقة الزمنية الحقيقية للجهاز (`flutter_timezone`)، مع زر لإرسال إشعار تجريبي فوري للتأكد من وصول التنبيهات.
- [x] **📿 عدّاد التسبيح:** سبحة إلكترونية كاملة داخل التطبيق مع إحصائيات لمتابعة الورد اليومي.
- [x] **📖 مكتبة الأذكار:** سبعة أقسام كاملة — الصباح، المساء، النوم، الاستيقاظ، أذكار بعد الصلاة، أدعية مختارة، والرقية الشرعية.
- [x] **⭐ المفضلة والمشاركة:** حفظ الأذكار المفضلة وتصفيتها، ومشاركة أي ذكر مع الأصدقاء بضغطة واحدة.
- [x] **🔤 تحكم في حجم الخط:** مؤشر انزلاقي لتكبير وتصغير نص الأذكار (من 14 إلى 35) مع حفظ الاختيار.
- [x] **🎨 واجهة نيونية ملكية:** تصميم داكن بالكامل (`Dark Mode`) يعتمد على اللون الأسود الملكي `#050505` مع لمسات مضيئة مريحة للعين ليلاً، بالإضافة إلى ثيم فاتح اختياري.
- [x] **⚙️ الحفاظ على الإعدادات:** حفظ مواعيد التنبيهات والثيم وحجم الخط والمفضلة باستخدام الـ `SharedPreferences`.
- [x] **🛠️ معالجة Android 13/14+:** طلب صلاحيات الإشعارات والمنبهات الدقيقة برمجياً لمنع كراشات النظام.
