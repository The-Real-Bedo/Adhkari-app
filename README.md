## 📖 نبذة عن التطبيق
**أذكاري** هو تطبيق إسلامي حديث وخفيف الوزن، تم بناؤه باستخدام **Flutter** ليقدم تجربة مستخدم فريدة وسلسة. يركز التطبيق على دقة المواعيد والشكل البصري الفاخر (النيوني) لمساعدة المسلم على المحافظة على أوراده اليومية دون تشتيت.

> ⚠️ **حالة المشروع الحالية:** التطبيق ما زال في مرحلة **التطوير النشط والمكثف (Under Development)**، ويتم تحديث الكود وإضافة ميزات جديدة بشكل دوري.

## ⚡ المميزات الحالية (Current Features)

- [x] **🔔 نظام إشعارات ذكي:** جدولة أذكار الصباح والمساء بدقة متناهية بناءً على المنطقة الزمنية الحقيقية للجهاز (`flutter_timezone`).
- [x] **🎨 واجهة نيونية ملكية:** تصميم داكن بالكامل (`Dark Mode`) يعتمد على اللون الأسود الملكي `#050505` مع لمسات مضيئة مريحة للعين ليلاً.
- [x] **⚙️ الحفاظ على الإعدادات:** حفظ خيارات المستخدم ومواعيد التنبيهات باستخدام الـ `SharedPreferences`.
- [x] **🛠️ معالجة Android 13/14+:** طلب صلاحيات الإشعارات والمنبهات الدقيقة برمجياً لمنع كراشات النظام.
